# 素材质量正式评分模型

- 模型版本：mq-quality-v1-20260824-py38
- 成熟样本：2524条，正GMV：833条，零GMV：1691条
- 子模型：画面50% + Luna脚本50%
- 标签：素材首个统计日起7日窗口内，日均GMV是否大于0
- 输出分数：相对训练样本分布的百分位，不是GMV金额预测
- 训练环境：Python 3.9.23 / NumPy 1.24.4 / scikit-learn 1.3.2

## 训练分数参考

- P10/P50/P90：0.376481 / 0.432104 / 0.513112
- 训练集AUC仅用于序列化自检：0.6518

## 使用限制

- 必须先完成同版本画面特征和Luna脚本特征抽取。
- 分数用于素材初筛和排序，暂不允许直接触发自动投放或停投。
- 新行业、平台接口或特征版本变化后必须重新做时间外评估。
