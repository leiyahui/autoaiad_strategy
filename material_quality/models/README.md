# 自研素材质量模型

公开仓库只保存模型卡和清单，模型权重及固定测试特征不上传。完整本地模型制品的每个版本
使用独立子目录，并与创建任务时记录的 `model_version` 一一对应。

每个版本必须同时包含：

- `model.joblib`：画面塔、脚本塔、融合权重和训练分布参考分。
- `manifest.json`：模型版本、特征版本、运行时版本和模型文件SHA256。
- `smoke_test.npz`：不包含原始视频和文本的固定数值输入及期望概率。
- `MODEL_CARD.md`：样本范围、指标、用途和限制。

本地发布新模型前必须确认模型摘要一致，并在锁定的Python环境运行Smoke Test。通用预训练
模型、用户视频、原始文本、训练样本及运行缓存不得放入该目录。
