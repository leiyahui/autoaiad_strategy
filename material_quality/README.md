# 素材质量模型模块

该模块保存 AutoAiAd Strategy 的样本构造、多模态特征、模型训练和推理验证代码。

## 目录边界

- `sample/`：标签窗口、样本范围和样本落库。
- `feature/`：媒体、画面、OCR、ASR、脚本和语义特征。
- `training/`：快照、时间切分、训练、消融和评估。
- `inference/`：固定特征Schema、模型校验和评分入口。
- `models/`：模型版本说明；模型权重和固定测试特征仅保存在本地。
- `sql/`：训练样本和特征表结构。
- `tests/`：纯计算、流水线和推理测试。

训练数据、用户素材、第三方模型权重、密钥及运行缓存不进入Git。数据库连接通过
`MATERIAL_QUALITY_DATABASE_URL` 提供，未配置时仅能运行不依赖业务数据库的测试。

当前模型 `mq-quality-v1-20260824-py38` 基于2524条历史素材训练，仅用于素材初筛和排序，
不允许直接触发自动投放或停投。
